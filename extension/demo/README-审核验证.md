# 知乎回答字数统计 | 阅读时间估算 — 审核验证说明（Reviewer Guide）

本文件面向 Microsoft Edge Add-ons / Chrome Web Store 的认证审核人员，说明如何在不登录知乎的前提下验证扩展的全部功能。

This file is a reviewer guide for the Microsoft Edge Add-ons / Chrome Web Store certification team.

## 1. 扩展做什么

在知乎问题页（`https://www.zhihu.com/question/*`）的每条回答正文开头，插入一条只读统计栏，显示：

- 汉字数 / 英文单词数 / 数字个数
- 总字数（三者之和）
- 预计阅读时间（汉字按 300 字/分钟、英文按 200 词/分钟折算，向上取整，最小 1 分钟）

统计栏为纯展示元素，`pointer-events: none`，不拦截页面点击，不修改回答内容，不发送任何网络请求。

## 2. 权限与数据处理

- 无 `permissions`，无 `host_permissions` 声明。
- 唯一注入范围：`https://www.zhihu.com/question/*`（content script 声明式注入）。
- 不读取、不存储、不上传任何用户数据。全部统计在页面本地内存中完成，页面关闭即丢弃。
- 无远程代码，无 `eval`，无外部资源加载。

## 3. 30 秒验证步骤（推荐：真实站点）

1. 安装扩展。
2. 打开：`https://www.zhihu.com/question/2081639111572698705/answer/2081671792847017848`
   未登录状态下打开该链接会弹出知乎的登录弹窗，这是知乎自身的行为，与扩展无关。审核验证时直接关闭该弹窗即可，无需登录、无需注册账号。
3. 等待约 2 秒，每条回答正文开头应出现蓝色左边框的统计条，内容形如：

   `字数： 汉 62 · Eng 0 · Num 0 ｜ 总 62 ｜ 阅读 ≈ 1 分钟`

4. 向下滚动或点击「查看全部回答」触发懒加载，新出现的回答会自动补上统计条。

如果该站点在审核环境不可访问，请改用第 5 节的离线验证方式。

## 4. 真实站点验证步骤

1. 打开：`https://www.zhihu.com/question/2081639111572698705/answer/2081671792847017848`
   未登录状态下打开该链接会弹出知乎的登录弹窗，这是知乎自身的行为，与扩展无关。审核验证时直接关闭该弹窗即可，无需登录、无需注册账号。
2. 页面加载约 2 秒后，每条回答正文开头出现统计条。
3. 点击“查看全部回答”或向下滚动触发懒加载，新出现的回答同样会自动获得统计条（扩展使用 `MutationObserver` 监听）。

## 5. 离线验证方式（备选）

如果知乎站点在审核环境不可访问，可用扩展自带的离线演示页：

1. 打开扩展目录下的 `demo/verify.html`（该页直接加载 `content.js`，不依赖扩展注入）。
2. 或在 `edge://extensions` 中为扩展开启「允许访问文件 URL」后打开 `demo/demo.html`。
3. 演示页复刻了知乎问题页的 DOM 结构（`.AnswerItem` / `.RichContent-inner`），打开后应看到同样的统计条渲染结果。
4. 演示页第 4 条回答正文为空，按预期不显示统计条。

## 6. 与 UserScript 版本的关系

本扩展是同名 UserScript（版本 4.3）的 Manifest V3 移植版。统计与注入逻辑逐行保持一致，仅做了以下移植性改动，不涉及功能变更：

- 移除 UserScript 元数据头；`@match` 迁移为 manifest 的 `content_scripts.matches`。
- `@grant none` 对应 manifest 不声明任何 `permissions`。
- 名称、`@namespace` 不再指向知乎官方域名，并在名称中标注“非官方”，避免与知乎官方产品混淆。

## 7. 已知限制

- 只对知乎问题页生效，其他页面（首页、专栏、回答详情页除外）不注入。
- 统计基于正文可见文本，折叠区域内的文本按知乎渲染结果计算。
- 阅读时间仅为按固定速率的粗略估算。
