# 商店文案（Edge Add-ons / Chrome Web Store 通用）

提交时把下面各段填进 Partner Center 对应字段。

商店列表按语言分开维护。**Edge 上传包后只自动生成默认语言那一条**，其他语言要手动
「添加语言」再逐条填，否则英文（美国）列表是空的，描述必填项会卡住提交。

| 语言 | 名称 | 描述 | 状态 |
| --- | --- | --- | --- |
| 中文（简体） | 知乎回答字数统计 \| 阅读时间估算 | 见下方「详细描述（中文）」 | 需在「商店列表」页手动添加 |
| English (United States) | 知乎回答字数统计 \| 阅读时间估算 | 见下方「Description (English, US)」 | 已添加 |

### 在 Partner Center 加中文列表

1. 左侧点 **店铺列表**（Store listings）
2. 页面上方 **添加语言** 下拉框里选 **中文（简体）**
3. 列表里出现新行，点该行的 **Edit details**
4. **扩展名** 只读，仍是 `知乎回答字数统计 | 阅读时间估算`。想换成纯中文名只能改
   `extension/manifest.json` 的 `name` 再发包，见下方「名称」一节的说明
5. **描述** 是必填项，粘贴「详细描述（中文）」那一段
6. **扩展徽标** 传 `extension/icons/icon300.png`
7. **截图** 传 1～6 张 640×480 或 1280×800。可以用列表行上的 **Duplicate**（先有一行
   传完截图后才会出现）把英文列表的截图复制过去，不用重复上传
8. 语言行出现绿色 **Complete** 后，右上角 **发布**

只保留中文一条、把英文那条 **Remove** 掉也可以，页面上写明了「您可以先移除其他语言」。
中国区用户能搜到，美国区搜不到，取舍看你。

名称在两条语言里都是只读的（来自 manifest 的 `name`），改不了。若上架后想让英文列表
也有英文名，只能改 manifest 的 `name` 再发新版。

## 名称（Extension name）

```
知乎回答字数统计 | 阅读时间估算
```

- 取自 manifest 的 `name` 字段，商店自动读取，只读不可改。**提交前务必确认，上架后不可改。**
- 竖线分隔主副功能：主功能「字数统计」在前，便于商店搜索命中；副功能「阅读时间估算」在后。
- 名称本身不含「官方 / 知乎出品 / Zhihu Inc.」等暗示官方身份的写法。商店详情页首段仍保留一句非官方声明，见下方「详细描述」结尾，兼顾问责与 1.1.2 描述准确性。

## Description (English, US)

Use this for the `English (United States)` listing. Plain text only: the store field does not
render Markdown, so `**bold**` and backticks would show up literally. Roughly 1,400 characters,
comfortably inside both the Edge and Chrome limits.

```
Know how long a Zhihu answer is before you start reading it.

This extension adds a small read-only bar to the top of every answer on a Zhihu question page. It shows the character count and an estimated reading time, so you can tell a three-minute answer from a thirty-minute one at a glance and spend your time on the ones worth reading.

What the bar shows:

- Chinese characters, English words, and digits, counted separately
- Total count, the sum of the three
- Estimated reading time: 300 Chinese characters per minute and 200 English words per minute, rounded up, one minute minimum

How to use it:

Install the extension and open any Zhihu question page. There is nothing to set up, no account to create, and no settings page. Answers that load later, when you scroll or click "View all answers", get the same bar automatically.

Your privacy:

The extension requests no browser permissions at all. It makes no network requests, loads no remote code, and does not collect, store, or transmit any data. Counting happens in your browser's memory, on the page you are already reading, and is discarded when you close the tab. There is no analytics, no telemetry, no cookies, and no local storage.

About this extension:

This is an unofficial, third-party tool. It is not affiliated with, authorized by, or endorsed by Zhihu (Beijing Zhizhi Tianxia Technology Co., Ltd.). The word "Zhihu" appears only to describe the website this extension works with.

The extension only runs on question pages. It was ported from a userscript of the same name, and both versions share the exact same counting logic.

Frequently asked questions:

Why do some answers have no bar?
Answers with empty content are skipped, and the extension only runs on question pages, not on the home feed, columns, or video pages.

How accurate is the reading time?
It is a rough estimate from fixed reading speeds, meant for comparison rather than precision.
```

## 详细描述（中文）

```
在知乎问题页阅读长回答时，很难事先判断哪条值得看。本扩展在每条回答的正文开头插入一条只读统计栏，让你先看体量再决定读不读。

显示内容：
· 汉字数、英文单词数、数字个数
· 总字数（三者之和）
· 预计阅读时间（汉字按 300 字/分钟、英文按 200 词/分钟折算，向上取整，最小 1 分钟）

使用方式：
安装后直接打开任意知乎问题页即可，无需登录、无需配置、没有设置页。向下滚动或点击「查看全部回答」时新加载的回答会自动补上统计栏。

隐私：
扩展不声明任何浏览器权限，不发起任何网络请求，不收集、不存储、不上传任何数据。全部统计在浏览器本地内存中完成，关闭页面即丢弃。

说明：
本扩展是第三方非官方工具，与知乎无关联、未获其授权或背书。「知乎」字样仅用于说明适用网站。

常见问题：
Q：为什么有的回答没有统计栏？
A：正文为空的回答会被跳过；另外扩展只在问题页 `https://www.zhihu.com/question/*` 生效，其他页面不注入。
Q：阅读时间准确吗？
A：是按固定速率的粗略估算，仅供参考。
```

## 商店图片素材

| 素材 | 要求 | 现状 |
| --- | --- | --- |
| 扩展图标 300×300 PNG | 必填 | 已有：`icons/icon300.png`（蓝底 #056DE8 圆角方块 + 白色「字」） |
| 截图 | **1～6 张**，尺寸须为 **640×480 或 1280×800**，PNG/JPEG | 已有：`screenshot.png`（原始整页图）与 `screenshot-1280x800.png`（合成图，可直接上传） |

| YouTube 视频（可选） | — | 不提供 |

尺寸口径：[Edge 商店文档](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)写的是 640×480 或 1280×800，
[Chrome 商店文档](https://developer.chrome.com/docs/webstore/images)写的是 640×400 或 1280×800。
**1280×800 两边都满足**，只做这一个尺寸即可。

### 截图说明

- `screenshot.png`：原始整页截图，2481×1523。尺寸不合规，而且整页缩到 1280 宽后统计条只有 5～6 px 高，审核员看不清。**不要直接上传这张。**
- `screenshot-1280x800.png`：由 `extension/tools/make-screenshot.ps1` 从上面那张合成，上半是统计条的放大视图，下半是页面中实际位置，正好 1280×800，可直接上传。
- 更省事的替代做法：浏览器窗口调到视口宽约 1280，再用 F12 设备工具栏（Ctrl+Shift+M）设成 1280×800 直接截视口。这样一张就是合规尺寸，统计条也是真实大小。
- 别把鼠标指针拍进画面。合成脚本会尝试识别并抹掉指针，但对真实的箭头指针识别不可靠，别指望它。
- 用 `认证备注.md` 里那个问题页截图，审核员对照方便。未登录会弹知乎登录框，属知乎自身行为，截图前关掉即可。

### 图标设计说明

- 造型：圆角方块（圆角半径 = 边长 23%）+ 单个白色汉字「字」，居中等宽留白。
- 配色：`#056DE8`，知乎站内主蓝色。
- 「字」直接指向功能本体（中文字数统计），与知乎自家「蓝底白字单字」的标志语言同源，但使用的是通用汉字而非知乎商标字形，不构成对官方标识的复制。
- 小尺寸表现：16/32/48 px 由 1024 px 主图 bicubic 缩放得到，笔画在 32 px 仍可辨。
- 可复现：`pwsh -File tools/render-icons.ps1` 重新生成全套；`-Ring` 可加阅读进度圆环，`-Design bars` 可切回柱状图版本。`icons/icon-source.svg` 为等价矢量参考稿。
