# 商店文案（Edge Add-ons / Chrome Web Store 通用）

提交时把下面各段填进 Partner Center 对应字段。

## 名称（Extension name）

```
知乎回答字数统计 | 阅读时间估算
```

- 取自 manifest 的 `name` 字段，商店自动读取，只读不可改。**提交前务必确认，上架后不可改。**
- 竖线分隔主副功能：主功能「字数统计」在前，便于商店搜索命中；副功能「阅读时间估算」在后。
- 名称本身不含「官方 / 知乎出品 / Zhihu Inc.」等暗示官方身份的写法。商店详情页首段仍保留一句非官方声明，见下方「详细描述」结尾，兼顾问责与 1.1.2 描述准确性。

## 简述（Short description，≤132 字符）

```
在知乎问题页的每条回答开头显示字数统计与预计阅读时间，只读展示，不收集任何数据。
```

## 详细描述（Description）

```
在知乎问题页阅读长回答时，很难事先判断哪条值得看。本扩展在每条回答的正文开头插入一条只读统计栏，让你先看体量再决定读不读。

显示内容：
· 汉字数、英文单词数、数字个数
· 总字数（三者之和）
· 预计阅读时间（汉字按 300 字/分钟、英文按 200 词/分钟折算，向上取整，最小 1 分钟）

使用方式：
安装后直接打开任意知乎问题页即可，无需登录、无需配置、没有设置页。向下滚动或点击「查看全部回答」时新加载的回答会自动补上统计栏。

隐私：
扩展不声明任何浏览器权限，不发起任何网络请求，不收集、不存储、不上传任何数据。全部统计在浏览器本地内存中完成，关闭页面即丢弃。

说明：
本扩展是第三方非官方工具，与知乎无关联、未获其授权或背书。「知乎」字样仅用于说明适用网站。

常见问题：
Q：为什么有的回答没有统计栏？
A：正文为空的回答会被跳过；另外扩展只在问题页 `https://www.zhihu.com/question/*` 生效，其他页面不注入。
Q：阅读时间准确吗？
A：是按固定速率的粗略估算，仅供参考。
```

## 权限理由（Justify permissions）

```
本扩展未声明任何 permissions 或 host_permissions。

它仅通过 manifest 的 content_scripts 声明式注入到 https://www.zhihu.com/question/*，
用于在页面内读取回答正文的可见文本并插入统计结果。所有计算在页面本地完成，
不访问其他站点，不读写浏览器存储，不发起网络请求。
```

## 远程代码（Remote code）


### 图标设计说明

- 造型：圆角方块（圆角半径 = 边长 23%）+ 单个白色汉字「字」，居中等宽留白。
- 配色：`#056DE8`，知乎站内主蓝色。
- 「字」直接指向功能本体（中文字数统计），与知乎自家「蓝底白字单字」的标志语言同源，但使用的是通用汉字而非知乎商标字形，不构成对官方标识的复制。
- 小尺寸表现：16/32/48 px 由 1024 px 主图 bicubic 缩放得到，笔画在 32 px 仍可辨。
- 可复现：`pwsh -File tools/render-icons.ps1` 重新生成全套；`-Ring` 可加阅读进度圆环，`-Design bars` 可切回柱状图版本。`icons/icon-source.svg` 为等价矢量参考稿。
