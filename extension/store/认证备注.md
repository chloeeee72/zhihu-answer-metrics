# 认证备注（Certification notes）

提交时粘贴到 Partner Center 的 **Certification testing notes / 认证测试说明** 字段。
审核员看不到你的仓库，只能看到这段文字与商店详情页，所以要把验证路径写全。

## 建议填入的文本

```
一、扩展功能
在知乎问题页（https://www.zhihu.com/question/*）的每条回答正文开头插入一条只读统计栏，
显示：汉字数 / 英文单词数 / 数字个数 / 总字数 / 预计阅读时间。
统计栏为纯展示元素（pointer-events: none），不拦截点击，不修改回答内容。

二、权限与数据
本扩展未声明任何 permissions 或 host_permissions，仅通过 content_scripts 声明式注入
https://www.zhihu.com/question/*。不发起任何网络请求，不加载远程代码，不读写浏览器存储，
不收集任何用户数据。

三、验证步骤（无需登录账号）
1. 安装扩展。
2. 打开：https://www.zhihu.com/question/2081639111572698705/answer/2081671792847017848
   未登录状态下打开该链接会弹出知乎的登录弹窗，这是知乎自身的行为，与扩展无关。
   审核验证时直接关闭该弹窗即可，无需登录、无需注册账号。
3. 等待约 2 秒，页面内每条回答的正文开头应出现蓝色左边框的统计栏，内容形如：
   「字数： 汉 62 · Eng 0 · Num 0 ｜ 总 62 ｜ 阅读 ≈ 1 分钟」
4. 向下滚动或点击「查看全部回答」触发懒加载，新出现的回答会自动补上统计栏。

四、登录墙说明
知乎对未登录访客会弹出登录弹窗，部分问题页还会限制可查看的回答数量。
该弹窗由知乎页面自身触发，本扩展不参与、不拦截、也不修改它；
关闭弹窗后页面内容正常显示，扩展统计栏照常注入。
验证地址：https://www.zhihu.com/question/2081639111572698705/answer/2081671792847017848
扩展本身不要求、也不引导用户登录，不做任何账号相关操作。

五、离线验证方式（备选）
若知乎站点在审核环境不可访问，扩展包内提供了本地演示页：
- 打开扩展目录下的 demo/verify.html（该页直接加载 content.js），
  或在 edge://extensions 中为本扩展开启「允许访问文件 URL」后打开 demo/demo.html。

  打开后应看到同样的统计栏渲染结果。
- 演示页第 4 条回答正文为空，按预期不显示统计栏。

六、已知限制
- 只在知乎问题页生效；知乎首页、专栏、视频页不注入。
- 阅读时间为按固定速率（中文 300 字/分钟、英文 200 词/分钟）的粗略估算。
- 统计基于正文的可见文本，折叠区域内文本按页面渲染结果计算。
```

## 原文的已知局限（照实交付，未擅自"改进"）

- 脚本 `setTimeout(..., 1200)` 固定延迟后扫描一次，随后交给 `MutationObserver`。知乎首屏若慢于 1.2 秒，首扫为空，但 observer 会补上，功能不受影响。
- `document.body` 不存在时 `observeGlobally()` 会抛错。MV3 下 content script 在 `document_idle` 运行，body 必然存在，风险比 UserScript 版更低。不改，避免偏离原逻辑。
- 统计栏用 `innerHTML` 拼接，插入的是纯 HTML 片段 + 数字，无用户可控文本进入该字符串，无注入面。不改。
- 站点条款：知乎用户协议对第三方脚本/扩展有保留条款。商店审核不查这一项，但权利人可发下架请求（DMCA / 商标投诉）。属不可通过技术手段消除的残余风险，已知悉。
